Two directions, neither of them a card

The first pass was competent and generic: rounded panels, soft shadows, a teal accent, and a rectangle that lights up under the pointer. These two start from what the platform is instead.

Direction A

Transcript

A conversation between two parties, written down and attributed in the margin, is an interview transcript. So it is set as one: Charter at a reading size, the speakers in the left margin in small sans, and no container around anything. A reply and the participant's own words are the same face at the same size, because they are the same kind of thing.

The two replies of a judgement are divided by one hairline and nothing else. There is no panel to make one of them look heavier, which is the hardest thing to get right and the easiest thing to get wrong.

Direction B

Instrument

The platform is a measuring device, so the screen is drawn as one. A fixed left column names every row, hairlines run the full width, and the sheet is held by two rules rather than floated on a shadow. Every label is monospaced and every reading is not, so a participant can always tell what the machine is saying from what a person said.

One colour, used only for what is live now. Everything the participant chose is black.

What both directions remove
  • Fill on hover A rectangle that lights up under the pointer is the cheapest signal there is. A pointer now moves an underline (A) or one marker character (B), and changes nothing else.
  • The card No radius, no shadow, no floating panel. Structure is a hairline and a column, which is what structure is on paper.
  • Avatars A rounded square holding the first letter of a name says nothing. The name says it.
  • The accent A is black on paper. B keeps one colour and spends it only on what is live now, never on decoration.
  • Pill switches And the theme toggle with them. Each direction commits to one look, which is the difference between a design and a set of options.
  • system-ui A is set in Charter, a reading face. B is set in a plain grotesk with a monospaced face for everything the machine says.
